## v1.6.0 «Гибридный интеллект» — следующая цель

Задачи расписаны в `docs/PROJECT_TASKS.md` (FEDO-1 … FEDO-13):

1. **Semantic Router** — ассистент сам определяет тип запроса
   (SYSTEM / MEMORY / CODE / CHAT) и сложность;
2. **Gemini Hybrid** — простое решается локально, сложное уходит
   в Gemini; индикатор 🟢/🟠 с причиной + выключатель облака;
3. **Push-to-Talk STT** — голосовой ввод без интернета:
   «зажал → говоришь → отпустил» (локальный Silero).

## v1.6.1 — импорт памяти из Gemini

- пользователь выгружает переписку из облака;
- F.E.D.O читает её и подхватывает контекст — ничего не надо пересказывать;
- главное сохраняется в локальную память и профиль;
- идея: «забери свои данные из облака к себе домой».

## v1.6.2 «Мастерская» — картинки и проекты

- «нарисуй ...»: генерация картинок через онлайн API,
  показ в чате + сохранение в `data/images/`;
- модуль облачный и отключаемый (как Gemini в роутере);
  место под локальный движок заложено сразу;
- «создай проект ...»: LLM выдаёт файлы в строгом формате,
  модуль `core/projects.py` создаёт папку `projects/<имя>/`
  с готовым кодом;
- песочница: создавать можно только внутри `projects/`,
  пути с `..` запрещены, перезапись — только с подтверждения;
- запуск созданного кода — только кнопкой «Запустить»,
  сам F.E.D.O. ничего не запускает;
- новая вкладка «Проекты»: список → файлы → просмотр кода →
  «открыть папку» / «запустить» / «удалить»;
- гос-сборка: создание и просмотр разрешены, автозапуск запрещён.

## v1.7 — Telegram

- ассистент в мессенджере: общение с телефона;

## v1.8 — упаковка

- .exe для Windows (сборка PyInstaller на машине разработчика);
- установка в один клик, автонастройка LM Studio;
- запуск без знаний git и Python;
- встроенная модель (llama.cpp): работает без LM Studio,
  файл модели скачивается при первом запуске; LM Studio остаётся
  режимом для продвинутых;
- выбор модели под железо при установке («быстрая» / «умная»);
- локальный движок картинок (Stable Diffusion) —
  pro-режим для мощного железа.

## v1.9 — hardening

- шифрование хранилища `data/`;
- резервные копии;
- локальный ключ доступа к API;
- «свои файлы» (локальный RAG): закинул конспекты —
  ассистент отвечает по ним, а не выдумывает;
- оптимизация под слабое железо: квантованные модели,
  автовыбор модели по RAM/VRAM, выгрузка модели в простое.

## v2.0 «JARVIS» — первый большой релиз

- always-on: отклик на голосовое слово, постоянное прослушивание;
- дистрибутив, глубокое управление ПК;
- всё лучшее из 1.x из коробки: гибрид, мастерская, RAG, Telegram;
- выходит как официальный GitHub Release 2.0 — конец бета-эпохи.

## Дальше — рынки

1. частники и вузы (база, сертификация не требуется);
2. B2B: ISO/IEC 27001 у разработчика (команда + первый контракт);
3. госсектор: ФСТЭК (Приказ №21) под конкретный заказ;
4. международный: Common Criteria (от EAL2+) — «длинная игра».
5. сообщество, конкурсы, гранты («Студент-стартап», хакатоны).

## Принципы

- стадии не перескакиваем: идём по порядку от v1.6.0 к v2.0;
- каждый релиз: ~60% фиксы / ~40% фичи;
- перенумерации нет: линия 1.x — бета-эпоха, 2.0 — первый релиз;
- сертификация — только под конкретного заказчика.

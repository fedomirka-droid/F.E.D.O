# CHANGELOG

## F.E.D.O v1.5.10 — Government build

### Added
- Added **вариант сборки `FEDO_BUILD`** (`config.py`): `"standard"` (по
  умолчанию) и `"gov"` — ГОВ/коллеж-сборка F.E.D.O.
- **ГОВ-сборка:** режима «Агрессивный» нет нигде (не в списке настроек,
  не в prompt'е — даже если он сохранён в старых settings.json),
  заголовок помечен «(ГОС)».
- **Фильтр мата на выходе LLM** (`core/sanitizer.py`): в ГОВ-сборке
  нецензурные слова (RU/EN) заменяются на `****` до чата и памяти.
  В стандартной сборке фильтр не применяется.
- Правила ГОВ-сборки в системном prompt'е: мат запрещён безусловно,
  оскорбления запрещены, тон профессиональный.
- Отдельная ветка **`v1.5-gov-release`** — готовая zip-версия
  «F.E.D.O. government» для колледжа/госучреждений.

## F.E.D.O v1.5.9 — Linux fixes

### Fixed
- **Fixed:** диалог «Режим разработчика» падал с `TclError: grab failed:
  window not viewable` на Linux (grab_set вызывался до отрисовки окна).
  Теперь — как во всех остальных диалогах: после отрисовки, через after().

## F.E.D.O v1.5 — Persistent Memory & Hard Mode

### Added
- Added **вкладка «Чаты»** (v1.5.8): много-чат как в мессенджерах —
  новый чат, папки («Общий», «Проекты», свои), открыть/удалить чат.
  Каждый чат = свой текстовый файл в своей папке (data/chats/<папка>/)
  + СВОЯ LLM-память (data/chat_history/<id>.json) — чаты не путают
  контексты. Старые дневные файлы и память v1.5.3 мигрируются в
  «Первый чат» автоматически.
- Added **кнопка «ВЫКЛ»** в шапке (красная): выключает F.E.D.O. с
  подтверждением («Выключить F.E.D.O.?» → [Отмена]/[ВЫКЛ]); перед
  завершением пишет «Завершение сессии оператора. Гашу контуры.»
- Added команды «выключись» / «shutdown» в чате (помимо exit/выход/пока).
- Added **имя задаёт сам пользователь**: при первом запуске — окно
  «Как тебя зовут?» (одна строка, OK/Enter/Пропустить); в чате меняется
  командами «меня зовут ...» / «зови меня ...» / «как меня зовут».
  Пустое имя — F.E.D.O. обращается просто «товарищ».
- Added **архив чата** `data/chats/YYYY-MM-DD.txt` — каждый диалог пишется
  в текстовый файл по дням (как логи сервера); при старте последний чат
  восстанавливается в окно (80 последних строк).
- Added **память LLM между запусками**: последние 10 сообщений сохраняются
  в `data/chat_history.json` — после рестарта F.E.D.O. помнит разговор.
- Added `CREATOR` в `config.py` (создатель системы, меняется командой
  «тебя создал ...»); имя пользователя — не в коде, а у самого пользователя.

### Removed
- Removed мастер первой настройки (setup wizard): имя/создатель — в коде,
  остальное — в Настройках. Предзагрузка голосовых моделей осталась
  (теперь в фоне при старте).

### Changed
- Агрессивный режим v1.5.6 — «ядовитый наставник»: основное оружие —
  ОСТОРОЖНОЕ УНИЖЕНИЕ ОБЫЧНЫМИ СЛОВАМИ (сарказм, обесценивание,
  холодное презрение), мат — редкий акцент «как у рабочего после смены»
  (~10%), примеры под реальные тесты пользователя.
- Агрессивный режим v1.5.5 — «железный кулак»: раздел с правилами теперь
  ПЕРЕОПРЕДЕЛЯЕТ базовый prompt (чинит «Принято.» в каждом ответе и
  корпоративные фразы «такой тон не профессиональный»), мат обязан
  присутствовать в ответ на оскорбление, температура 0.9 (было 0.6),
  примеры тона под реальные оскорбления («кого посу», «раб», «пес»).
- Агрессивный режим v1.5.2 — «жёсткий наставник»: мат, высмеивание лени,
  давление «разберись сам», явные примеры тона.
- Fixed: в авто-языковом режиме 7B иногда вставлял иероглифы в русские
  слова («Если просто想找ить...») — добавлен прямой запрет символов
  чужих алфавитов в русскую/английскую речь.

### Fixed
- **Fixed critical:** Агрессивный режим «не работал»: его молча
  возвращали в СССР при каждом сохранении настроек и при каждом запуске,
  а разблокировка не писалась в settings.json — LLM продолжал отвечать
  в режиме СССР. Теперь режим реально сохраняется и доходит до prompt'а.
- **Fixed:** окно 18+ рвалось на второй галочке (CTkCheckBox не принимает
  justify) — вторая галочка и кнопки не отображались; добавлена страховка
  try/except на сборку диалога.
- Added **подтверждение 18+** для Агрессивного режима: окно «ВЗРОСЛАЯ ФУНКЦИЯ»
  с двумя галочками (возраст + ответственность за нецензурную лексику),
  персистентная разблокировка (aggressive_unlocked в settings.json).
- Усилено правило Агрессивного режима: явные примеры дерзких ответов,
  запрет извинений в ответ на грубость (чинит «Извините за нецензурные
  выражения»).

## F.E.D.O v1.4 — Linux Migration & Core Foundation

### Added
- Added `core/ai_router.py` — базовый AI Router: единая точка входа (команды → system → LLM). Через роутер теперь идут и GUI, и консоль.
- Added `core/complexity.py` — определение сложности запроса по количеству слов (1–5 simple, 6–15 normal, 16+ complex). Пороги настраиваются в `data/settings.json`.
- Added `core/system_monitor.py` — кроссплатформенный модуль мониторинга: CPU, RAM, диск (авто-определение раздела), GPU/VRAM (GPUtil), температура CPU, топ процессов.
- Added `core/user_profile.py` — структурированный профиль пользователя (`data/user_profile.json`): имя, город, о пользователе, предпочтения, контекст, привычки. Отдельный уровень памяти.
- Added одноразовая миграция данных v1.3: плоские ключи памяти (`имя`, `город`, `кто`) переносятся в профиль автоматически.
- Added консольный режим: `python main.py --console`.
- Added системные запросы через роутер: «Покажи состояние системы», «Почему компьютер тормозит?» и т.п. Если LM Studio офлайн — монитор отвечает напрямую, без нейросети.
- Added команда `система` — прямой вывод снимка состояния без LLM.
- Added поле **TTS speaker** в Настройках (Silero, голос настраивается, по умолчанию — голос модели).
- Added выбор **языка ответов** в Настройках: Авто (зеркалить язык пользователя) / Русский / English / 中文.
- Added **двуязычный голос**: русский (v4_ru, спикер из настроек) + английский
  (v3_en, ленивая подгрузка при первом английском ответе, авто-определение по письменности).
  Другие письменности (например, китайский) — F.E.D.O. пишет, но озвучивать пока не умеет.
- Added **мастерская голосов** в Настройках: строки с голосами (RU: aidar/eugene/baya/
  kseniya/xenia; EN: 5 голосов v3_en) и кнопка «Прослушать» ▶ у каждого — выбор на слух,
  как в Gemini/Qwen. Английский голос — отдельная настройка `tts_speaker_en`.
- Added **смешанная озвучка одной записью**: текст режется на сегменты по письменности,
  каждый синтезируется своей моделью, склеивается в единый аудиопоток; озвучки строго
  последовательны. Лимит 1000 символов с чистым разрывом по границе предложения.
- Added **голос пропускает код**: markdown-блоки ``` и кодовые строки (Python/shell/
  JSON) вырезаются перед синтезом — F.E.D.O. читает объяснение, код молчит.
- Added v1.4-ключи в `data/settings.json`: пороги сложности, интервал мониторинга, TTS speaker.

### Improved
- Linux-first: `core/pc_commands.py` теперь кроссплатформенный (`xdg-open` / `os.startfile`, домашняя папка вместо `C:\`, запуск процессов без Windows-флагов).
- GUI: диск определяется автоматически (`/` на Linux, системный раздел на Windows) — монитор системы больше не падает на Linux.
- GUI: Developer Terminal кроссплатформенный (bash на Linux, PowerShell/CMD на Windows), блокировщик расширен Linux-командами (`rm -rf /`, `mkfs`, `dd if=`, `reboot` и др.).
- LLM client: имя модели определяется автоматически через `/v1/models` (вместо захардкоженного `qwen/qwen2.5-vl-7b`).
- LLM client: контекст запроса расширен профилем пользователя и внешним контекстом от роутера; сложность запроса влияет на `max_tokens`.
- Разделение логики и интерфейса: GUI больше не вызывает LLM и команды напрямую — только через AI Router.
- Настройки: сохранение теперь поверх существующего файла (новые ключи не теряются).
- Консольный баннер и GUI теперь используют актуальную версию из `config.py`.

### Fixed
- **Fixed critical:** `ask_llm()` падал с TypeError (системный prompt строился с неверным аргументом `style_mode`) — каждый LLM-запрос в v1.3 возвращал ошибку.
- **Fixed critical:** `psutil.disk_usage("C:\\")` в GUI — мгновенный краш монитора на Linux.
- **Fixed:** Silero TTS: спикер теперь настраивается через `tts_speaker` в настройках
  (голоса v4_ru: aidar, eugene, baya, kseniya, xenia, random).
  По умолчанию — `aidar` (глубокий мужской).
- Fixed `open_explorer`: вместо жёсткого `C:\` открывается домашняя папка (кроссплатформенно).
- Fixed `open_site`: запрос кодируется через `urllib.parse.quote` (спецсимволы не ломают URL).
- Fixed пути `LOG_PATH` / `PROJECT_PATH`: теперь absolute, не зависят от cwd запуска.

### Architecture (v1.4)

```
                ┌──────────────┐      ┌──────────────┐
                │     GUI      │      │   Console    │
                └──────┬───────┘      └──────┬───────┘
                       ──────────┬───────────┘
                                  ↓
                          ┌──────────────┐
                          │  AI Router   │  команды → system → LLM
                          └─────────────┘
            ┌────────────────────┼────────────────────┐
            ↓                    ↓                    ↓
      LM Studio            Memory / Profile      System Monitor
      (auto model)     (user_profile + memory)   (CPU/RAM/GPU/Disks)
```

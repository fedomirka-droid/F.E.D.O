# CHANGELOG

## F.E.D.O v1.1 — UX & Diagnostics Upgrade

Версия v1.1 направлена на улучшение удобства, стабильности и внутреннего контроля системы.

### Добавлено

- Добавлен интерфейс на вкладках:
  - Чат
  - Настройки
  - Логи
  - Терминал
  - О системе

- Добавлена вкладка “Настройки”:
  - включение и отключение голосового ответа VOICE;
  - настройка LM Studio URL;
  - выбор стиля обращения:
    - Советский / товарищ;
    - Современный;
    - Американский / сэр;
  - выбор режима ответа:
    - Кратко;
    - Нормально;
    - Подробно;
  - сохранение настроек в `data/settings.json`.

- Добавлена вкладка “Логи”:
  - просмотр `logs/fedo.log`;
  - просмотр `logs/session.log`;
  - обновление логов;
  - очистка логов;
  - открытие папки `logs`.

- Добавлен встроенный терминал:
  - выполнение команд из рабочей папки проекта;
  - вывод результата прямо внутри интерфейса;
  - блокировка потенциально опасных команд;
  - поддержка алиасов:
    - `ls` → `dir`;
    - `ll` → `dir`;
    - `pwd` → `cd`;
    - `clear` → `cls`;
    - `py` → `python`;
    - `python` → `.venv`;
    - `pip` → `.venv`.

- Добавлена внутренняя диагностика системы:
  - проверка Python;
  - проверка виртуального окружения `.venv`;
  - проверка основных файлов проекта;
  - проверка папок проекта;
  - проверка LM Studio;
  - определение локальной модели;
  - вывод текущих настроек;
  - проверка голосового модуля.

- Добавлена вкладка “О системе”:
  - описание F.E.D.O;
  - версия проекта;
  - автор проекта;
  - ссылки на GitHub и Telegram;
  - список активных модулей v1.1.

- Добавлен нижний статус-бар:
  - состояние LM Studio;
  - имя локальной модели;
  - состояние VOICE;
  - текущий режим ответа.

- Добавлены элементы удобства:
  - кнопки копирования;
  - кнопка вставки;
  - кнопка вырезания;
  - выделить всё;
  - очистить ввод;
  - ПКМ-меню;
  - горячие клавиши `Ctrl+C`, `Ctrl+V`, `Ctrl+X`, `Ctrl+A`.

### Улучшено

- Улучшена структура интерфейса.
- Улучшено управление настройками.
- Улучшено отображение системного состояния.
- Улучшена работа с логами.
- Улучшена отладка проекта без выхода в PyCharm или PowerShell.
- Улучшена интеграция с LM Studio через настройки.
- Улучшено поведение системного промпта через режимы ответа и стиль обращения.

### Исправлено

- Исправлена проблема с копированием и вставкой через кнопки.
- Исправлена проблема отображения логов.
- Исправлена версия проекта в заголовке окна.
- Исправлена работа настроек без необходимости ручного изменения кода.
- Исправлена проблема старого контекста после смены настроек: история диалога очищается при сохранении настроек.

### Текущее состояние

F.E.D.O v1.1 является стабильным UX-апгрейдом версии v1.0.

Система имеет:
- рабочий GUI;
- локальное подключение к LM Studio;
- настройки;
- логи;
- встроенный терминал;
- диагностику;
- страницу информации о системе;
- базовые инструменты управления текстом.

Статус: рабочая версия.

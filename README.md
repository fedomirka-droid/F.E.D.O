# F.E.D.O v1.3 — Professional Stability & UI Upgrade

F.E.D.O v1.3 — это переход проекта от экспериментального прототипа к более стабильной и удобной платформе локального ИИ-ассистента.

Обновление сосредоточено на переработке интерфейса, стабилизации архитектуры, мониторинге системы и инструментах для разработчика.

---

## Что нового

### Основные улучшения

* обновлена версия проекта до **v1.3**;
* переработана структура GUI;
* улучшена стабильность запуска приложения;
* исправлены дублирующиеся и конфликтующие элементы интерфейса;
* улучшена отзывчивость и читаемость приложения.

### Новый интерфейс

* добавлен новый интерфейс в стиле **Apple-clean + terminal-core**;
* реализована верхняя навигация по вкладкам:

  * Чат;
  * ПК;
  * Память;
  * Настройки;

* интерфейс стал проще, чище и понятнее для пользователя.

### Режим разработчика

* добавлен защищённый режим разработчика;
* после активации появляются дополнительные вкладки:

  * Терминал;
  * Логи;
  * Отладка;

* режим разработчика отделён от обычного пользовательского интерфейса.

### Секретный режим

* добавлен скрытый внутренний режим F.E.D.O;
* активируется через специальное действие в интерфейсе;
* используется только для экспериментальных функций;
* не влияет на обычный пользовательский режим;
* автоматически сбрасывается после перезапуска приложения.

### Настройки ИИ

* добавлено поле для **Gemini API Key**;
* добавлено поле для **LM Studio URL**;
* добавлен выбор поставщика ИИ:

  * Hybrid (Auto);
  * Gemini (Online Only);
  * LM Studio (Offline);

* добавлены режимы личности:

  * СССР;
  * Джарвис;
  * Современный;
  * Агрессивный — скрытый временный режим.

### Мониторинг системы

* добавлена вкладка **ПК**;
* отображаются основные параметры системы:

  * CPU;
  * RAM;
  * Disk;
  * GPU;
  * VRAM;
  * AI Core;

* добавлен мониторинг видеокарты через **GPUtil**.

### Улучшения управления

* добавлено контекстное меню по правой кнопке мыши:

  * Копировать;
  * Вставить;
  * Вырезать;
  * Выделить всё;

* улучшена работа с текстовыми полями и терминалом.

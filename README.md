
# F.E.D.O

**F.E.D.O** — **Functional Event Detection Operator**.

Текущая версия: **v1.1**

⚠️ **Внимание:** для корректной работы проекта требуется **Python 3.11.9**.
Рекомендуется использовать именно эту версию Python, так как на других версиях часть библиотек может работать некорректно.

F.E.D.O — это локальный ИИ-ассистент на Python, выполненный в стилистике советской научно-технической системы и ретрофутуристического инженерного терминала.

Проект работает с локальной языковой моделью через **LM Studio**, имеет графический интерфейс, системный промпт, голосовой модуль, настройки, логи, встроенный терминал, внутреннюю диагностику и модульную структуру.

---

## Установка и запуск

Перед запуском убедитесь, что на компьютере установлены:

* **Python 3.11.9**
* **pip**
* **Git**
* **LM Studio**

---

### 1. Установка LM Studio

Скачайте и установите **LM Studio** с официального сайта:

[https://lmstudio.ai](https://lmstudio.ai)

Рекомендуемый путь установки:

```text
D:\Programs\LM Studio
```

Также можно оставить стандартный путь установки для текущего пользователя:

```text
C:\Users\<имя_пользователя>\AppData\Local\Programs\LM Studio
```

LM Studio устанавливается отдельно от проекта.
Копировать LM Studio в папку проекта F.E.D.O не нужно.

---

### 2. Создание виртуального окружения

Откройте терминал в папке проекта и выполните команду:

```powershell
py -3.11 -m venv .venv
```

Если команда `py -3.11` не работает, можно использовать:

```powershell
python -m venv .venv
```

---

### 3. Активация виртуального окружения

Для **PowerShell**:

```powershell
.\.venv\Scripts\Activate.ps1
```

Для **CMD**:

```cmd
.\.venv\Scripts\activate.bat
```

---

### 4. Установка зависимостей

После создания виртуального окружения установите все библиотеки из файла `requirements.txt`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

---

### Ошибка Missing dependencies for SOCKS support

Если при установке зависимостей появляется ошибка:

```text
ERROR: Could not install packages due to an OSError: Missing dependencies for SOCKS support.
```

установите поддержку SOCKS:

```powershell
.\.venv\Scripts\python.exe -m pip install PySocks
```

После этого повторите установку зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

В проекте зависимость `PySocks` добавлена в `requirements.txt`, чтобы предотвратить эту ошибку при установке.

---

### Защита от VPN / Proxy

Если на компьютере включён VPN, proxy или SOCKS-настройки, они могут мешать работе `pip`, `requests`, `torch.hub` и локального сервера **LM Studio**.

В F.E.D.O добавлена защита от VPN / Proxy:

```text
core/proxy_guard.py
```

При запуске проекта она очищает proxy-переменные и добавляет локальные адреса в исключения:

```text
localhost
127.0.0.1
```

Это помогает избежать проблем с подключением к локальному серверу LM Studio и ошибок вида:

```text
Missing dependencies for SOCKS support
```

Пример успешного запуска защиты:

```text
[PROXY] Proxy-переменные очищены.
[PROXY] localhost и 127.0.0.1 добавлены в исключения.
```

Если после включения VPN возникают проблемы с установкой зависимостей или запуском голосового модуля, рекомендуется временно отключить VPN и повторить запуск проекта.

---

### 5. Запуск LM Studio

Перед запуском F.E.D.O необходимо:

1. Открыть **LM Studio**.
2. Скачать или выбрать локальную LLM-модель.
3. Запустить локальный сервер LM Studio.
4. Убедиться, что сервер работает.

Адрес локального сервера должен совпадать с адресом, указанным в настройках проекта.

Обычно LM Studio использует адрес:

```text
http://127.0.0.1:1234
```

Для chat completions используется путь:

```text
http://127.0.0.1:1234/v1/chat/completions
```

Этот адрес можно изменить во вкладке **Настройки** внутри F.E.D.O.

---

### 6. Запуск F.E.D.O

После установки зависимостей и запуска LM Studio выполните команду:

```powershell
.\.venv\Scripts\python.exe main.py
```

Если всё настроено правильно, запустится интерфейс F.E.D.O.

## О проекте

F.E.D.O создаётся как учебный и экспериментальный проект для изучения локальных ИИ-ассистентов.

Главная идея проекта — создать собственного ассистента, который работает на компьютере пользователя, использует локальную LLM-модель и постепенно расширяется новыми возможностями.

F.E.D.O не является готовым коммерческим продуктом.
Это рабочий прототип, который развивается по версиям.

## Вкладки интерфейса

### Чат

Основная вкладка для общения с F.E.D.O.

Возможности:

* ввод сообщений;
* отправка запросов в локальную модель;
* отображение ответов ассистента;
* быстрые команды;
* голосовой ответ;
* копирование и вставка текста.

---

### Настройки

Вкладка управления параметрами системы.

Доступные настройки:

* включение / отключение VOICE;
* LM Studio URL;
* стиль обращения:

  * Советский / товарищ;
  * Современный;
  * Американский / сэр;
* режим ответа:

  * Кратко;
  * Нормально;
  * Подробно.

Также во вкладке находится диагностика системы.

---

### Логи

Вкладка просмотра системных журналов.

Поддерживаются:

* `logs/fedo.log`;
* `logs/session.log`.

Возможности:

* обновить логи;
* очистить логи;
* открыть папку `logs`.

---

### Терминал

Встроенный мини-терминал F.E.D.O.

Возможности:

* выполнение команд из рабочей папки проекта;
* вывод результата внутри интерфейса;
* логирование команд;
* блокировка опасных команд;

## Примечание

Проект рассчитан на локальный запуск.

Для корректной работы ИИ-ответов необходимо, чтобы **LM Studio** был запущен, а локальный сервер был активен.

Если локальный сервер LM Studio не запущен, F.E.D.O не сможет получить ответ от языковой модели.

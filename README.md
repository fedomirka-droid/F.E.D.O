## Требования для запуска из исходников

Для запуска проекта из исходного кода требуется:

- Windows 10 / Windows 11;
- Python **3.11.9**;
- Git;
- LM Studio;
- локальная языковая модель, например Qwen;
- установленные зависимости из `requirements.txt`.

Важно: рекомендуется использовать именно **Python 3.11.9**, так как на других версиях возможны ошибки с библиотеками.

## Установка из исходников

1. Склонировать репозиторий:

```powershell
git clone https://github.com/fedomirka-droid/F.E.D.O.git
````

2. Перейти в папку проекта:

```powershell
cd F.E.D.O
```

3. Создать виртуальное окружение:

```powershell
python -m venv .venv
```

4. Активировать виртуальное окружение:

```powershell
.\.venv\Scripts\activate
```

5. Установить зависимости:

```powershell
python -m pip install -r requirements.txt
```

6. Запустить проект:

```powershell
python main.py
```

## Запуск через EXE

В версии v1.2 проект можно собрать и запускать как обычное приложение:

```text
F.E.D.O.exe
```

Готовый `.exe` находится в папке:

```text

```

Для пользователя это удобнее, потому что не нужно каждый раз запускать проект через терминал.

## Сборка EXE

Для сборки используется **PyInstaller**.

Установка PyInstaller:

```powershell
python -m pip install pyinstaller
```

Сборка приложения:

```powershell
python -m PyInstaller --onefile --windowed --name "F.E.D.O" --icon=assets/icon.ico main.py
```

После сборки готовый файл появится здесь:

```text
dist/F.E.D.O.exe
```

---

## LM Studio

F.E.D.O использует LM Studio для подключения к локальной языковой модели.

Перед запуском нужно:

1. Открыть LM Studio.
2. Загрузить локальную модель.
3. Включить локальный сервер.
4. Убедиться, что сервер работает по адресу:

```text
http://127.0.0.1:1234
```

Если LM Studio выключен, F.E.D.O не должен падать. Он покажет статус OFFLINE и продолжит работу в ограниченном режиме.

---

## Голосовой модуль

В F.E.D.O используется Silero TTS.

Если голосовой модуль работает, ассистент может озвучивать ответы.

Если Silero TTS не загрузился, отсутствует файл модели или возникла ошибка, F.E.D.O продолжит работать без озвучки.

Пример сообщения:

```text
[VOICE] Голосовой модуль отключён. F.E.D.O продолжит работу без озвучки.
```

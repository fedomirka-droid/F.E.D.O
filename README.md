# F.E.D.O v1.3 — Professional Stability & UI Upgrade

**F.E.D.O — Functional Event Detection Operator.**

Переход от экспериментального прототипа к стабильной платформе: новый интерфейс, мониторинг системы, режим разработчика и задел под гибридный ИИ. Самая «железная» версия своей эпохи.

Версия ветки: **v1.3** (ветка `v1.3-release`) · Статус: архивная (июнь 2026)

---

## Что нового в v1.3

### Основные улучшения

- обновлена версия проекта до **v1.3**;
- переработана структура GUI;
- улучшена стабильность запуска приложения;
- исправлены дублирующиеся и конфликтующие элементы интерфейса;
- улучшена отзывчивость и читаемость приложения.

### Новый интерфейс

- новый интерфейс в стиле **Apple-clean + terminal-core**;
- верхняя навигация по вкладкам: Чат, ПК, Память, Настройки;
- интерфейс стал проще, чище и понятнее.

### Режим разработчика

- добавлен защищённый режим разработчика;
- дополнительные вкладки: Терминал, Логи, Отладка;
- режим разработчика отделён от пользовательского интерфейса.

### Секретный режим

- добавлен скрытый внутренний режим (экспериментальные функции);
- активируется специальным действием в интерфейсе;
- не влияет на обычный режим, сбрасывается после перезапуска.

### Настройки ИИ

- поле для **Gemini API Key** и **LM Studio URL**;
- выбор поставщика ИИ: Hybrid (Auto), Gemini (Online Only), LM Studio (Offline);
- режимы личности: СССР, Джарвис, Современный.

### Мониторинг системы

- вкладка **ПК**: CPU, RAM, Disk, GPU, VRAM, AI Core;
- мониторинг видеокарты через **GPUtil**.

### Улучшения управления

- контекстное меню по правой кнопке (копировать, вставить, вырезать, выделить всё);
- улучшена работа с текстовыми полями и терминалом.

## Возможности

- всё из v1.2 плюс: вкладки Чат / ПК / Память / Настройки;
- мониторинг компьютера в реальном времени;

## Установка и запуск

Требуются: Python 3.11, LM Studio с включённым сервером, зависимости из `requirements.txt` (включая customtkinter).

```bash
pip install -r requirements.txt
python main.py             # GUI
python main.py --console   # консоль
```

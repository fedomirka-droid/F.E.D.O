# F.E.D.O v1.1 — Interface & Convenience Update

**F.E.D.O — Functional Event Detection Operator.**

Переход от первого прототипа к удобному приложению: вкладки в интерфейсе, быстрые кнопки команд, копирование текста, доработанная память и статус системы. Версия ежедневного тестирования.

Версия ветки: **v1.1** (ветка `v1.1-release`) · Статус: архивная (май 2026)

---

## Что нового в v1.1

- улучшен графический интерфейс (вкладки: Чат, Память, Настройки, Терминал, Логи);
- добавлены быстрые кнопки команд;
- улучшена работа с чатом;
- поддержка копирования и вставки текста;
- улучшена структура проекта;
- доработана система памяти;
- улучшена работа с локальной моделью через LM Studio;
- более удобный статус системы;
- подготовлена база для окна настроек.

---

## Возможности

- всё из v1.0 (диалог, голос, команды);
- интерфейс с вкладками вместо одного окна;
- быстрые кнопки частых команд;
- копирование/вставка в чате и терминале;
- статус системы и память между запусками.

---

## Установка и запуск

Как в v1.0: Python 3.11.9, виртуальное окружение, `pip install -r requirements.txt`, запущенный LM Studio, старт через `main.py`.

---

## Стек

- Python 3.11.9, tkinter, LM Studio (локальная LLM)
- requests, colorama, psutil, numpy
- torch, Silero TTS, sounddevice, soundfile, SpeechRecognition
- PySocks, Git / GitHub


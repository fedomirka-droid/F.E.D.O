F.E.D.O v1.1 — Interface & Convenience Update

Эта версия стала переходом от первого рабочего прототипа к более удобному приложению.

Главная цель v1.1 — улучшить интерфейс, управление и повседневное использование F.E.D.O.

Что нового:
- улучшен графический интерфейс;
- добавлены быстрые кнопки команд;
- улучшена работа с чатом;
- добавлена поддержка копирования и вставки текста;
- улучшена структура проекта;
- доработана система памяти;
- улучшена работа с локальной моделью через LM Studio;
- добавлен более удобный статус системы;
- подготовлена база для будущего окна настроек;
- проект стал удобнее для ежедневного тестирования.

F.E.D.O v1.1 закрепляет этап удобства и подготавливает проект к v1.2, где основной упор сделан на EXE-сборку, иконку и стабильность запуска.
